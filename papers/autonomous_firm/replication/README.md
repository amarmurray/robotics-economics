# The Autonomous Firm — numerical replication
Research discussion edition, 20 November 2026 (US Eastern).

Use Python 3.10 or newer. From this extracted directory, run:

    python run_all.py

All six economic calculation modules use the Python standard library. The inputs
are in the module source. The script runs all checks, writes results to stdout,
and exits on the first failure. reference_output.txt records the verified run.

| Module | Question |
|---|---|
| probe_checks.py | Which inherited training organization buys the field signal as an unrelated deadline raises the cost of pooling? |
| physics_checks.py | How do common-state failures change overflow, reserve-slot value and the marginal economic cost of an error? |
| control_checks.py | How does a one-round delay change price feedback stability, and when do slot bundles require joint allocation? |
| labor_checks.py | How do throughput, demand and support intensity change billed hours, operator hours and contribution? |
| dispatch_checks.py | When should the operator collect a new demonstration or train across six digital/physical shifts? |
| retained_checks.py | Can paid source observations change a repeated investment decision on a held-out target? What if the shared relation disappears? |

All simulations and examples use artificial parameters, except for explicitly
identified terms of the public hourly-price illustration. The recurrence, binomial
mixture and conditional choices are solved or enumerated directly. There is no
external data feed, proprietary customer sample, trained LLM or field estimate.
The PDF gives the source evidence, diagrams and assumptions.
