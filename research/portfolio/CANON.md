## One shared notation table

Canonical notation applies to new text. A retained proof using legacy notation must provide an explicit local translation; wholesale silent relabeling is forbidden.

| Object | Shared notation / definition | Do not conflate with |
| --- | --- | --- |
| Accepted service | y^acc_(j,t), task/configuration-specific completed output meeting the stated acceptance rule | Announced units, attempts, raw cycles or benchmark accuracy |
| Embodied capital | K_(r,t), installed/usable embodiment r; pending orders separately | Model weights, qualified policy or cash |
| Accepted-service robot marginal product | MPK_r = directional marginal accepted service from K_r under a stated comparator and horizon | Profit, reward, market value or an untyped scalar intelligence score |
| Firm-value response | Delta V_i / Delta K_r or a stated value derivative, with rivals/markets held fixed or reoptimized explicitly | Physical MPK_r; downstream value must not be added twice |
| Dated spendable cash | B_(a,t), by legal payer a and date t | Receivables, contract liabilities, revenue, project value or capitalized labor |
| Receivables | AR_(a,t), with due date, collectibility and financing terms | Collected cash |
| Qualification probability | p^qual_(s→j), conditional on target, budget, installed hardware, protocol and permitted evidence | Source success, classifier accuracy or unrestricted transfer probability |
| Transfer kernel | T_(s→j)(outcome | evidence, procedure, configuration, rights, resources) | Production-input adjacency or payment links |
| Evidence and permissions | D; R^use_(s→j) for lawful use/transfer | Possession, public disclosure or unrestricted AI/ML training rights |
| Retained procedure | psi, with a specified effect on future experiment/qualification choices | The executor’s accuracy alone |
| Three networks | A^Y for production requirements, A^L for qualified learning links, A^F for enforceable funding links | One universal adjacency matrix |
| Cash-time occupancy | m_j = integral b_j(s) ds, in money × elapsed time | A monetary cost or an unrestricted growth rate |
| Opportunity indicator / investment | I^opp for the timing/covariance indicator; i_(j,t) for investment flow | Reuse of an unqualified I in incompatible propositions |

Legacy evidence-allocation $B,E,m$ become $H^{free},\mathcal H,z$; $B$ remains spendable cash. ## Referee and handoff protocol

A referee packet identifies paper/claim IDs, source version, proposed contribution, closest prior art, precise assumptions, proof/replication references and empirical scope. The reviewer is not the author. Each objection receives an ID, severity, proposed defeating case, disposition (resolved by proof / narrowed claim / explicit unresolved boundary), evidence and author response. Gate B passes only when each substantive objection is resolved by evidence or proof, or the affected claim is narrowed so that the objection becomes an explicit valid boundary. An unresolved objection that defeats a retained claim keeps B pending; acknowledgment alone does not clear it. Current B status for all three papers is pending.

Every lane handoff records input SHA, claim owner, files changed or proposed, evidence classification, explicit nulls, tests actually performed, gate status and the next falsifiable question. The coordinator and canon steward reject duplicate claim ownership or an unregistered monograph before publication.
