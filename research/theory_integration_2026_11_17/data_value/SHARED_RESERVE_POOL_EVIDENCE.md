# Prospective pooled reserve and lineage audit

Unit: whole original buyer/worker interference catchment across a dated dispatch horizon; preserve all initial order IDs, prices, deadlines, failures, refusals and subsequent distinct buyer authorizations. Freeze original population before arm assignment. Record controller versions, training source lineages, report timing, actual worker availability and conservative safe action masks. Report synchronized calls before dispatch, not merely realized calls after a worker has been allocated (the latter is capacity-censored). Record call starts, duration, cross-site travel/coordination and backlog. Do not infer safety from observed zero failures.

Factorial approved arms R/X/G/E, actual purchased K and G+K; randomize at whole-pool level only where independently safe/authorized. Include isolated reference arms if transport is to be tested, not as substitutes for pooled trials. Estimate original-denominator p_A,p_B,j separately by arm; log both called and uncalled clusters' accepted receipts, displacement, lineages, rights, curation/compute, and held-out successor service maturity. Identify the incremental paid-plus-continuation contrast of a call against the same full-report no-call baseline, conditional on competing calls. Treat postaction lineage as a mediator rather than assuming its marginal law invariant. Use actual idle purchase costs, report drift, and displaced other work. If call assignment is deterministic with no support for the other safe option, state the unidentifiable contrast and use a validated bound or a supported feasible witness. No deliberately unsafe trials.

In the toy, separate per-cluster demand and isolated premium audits do not identify j; joint report prevalence plus conditional simultaneous-call net economics is sufficient given the other stipulated parameters. G+K beats E for j<1/64, but with uncertain payoffs use the paired common-law contrast, not a plug-in threshold. For dynamic extension, retain worker carryover and successor identities instead of summing isolated slot value. Track changes in duration, not only count, and validate joint resource conservation. A reserve pool may have geographic access restrictions; a nominal worker is not a feasible slot. No actual trial, rights agreement, original order panel or new numeric BEA/BLS crosswalk acquired. Existing official numeric BLS rows retained, missing official BEA matrix remains a distinct unresolved evidence obligation.

Audit whether version switching is possible at the relevant report time. Retaining an ex ante old program is not the same as per-report or per-site hybrid selection. If hybrid is permitted, the countermodel menu is incomplete; estimate its conditional outcomes or use a supported relaxation rather than asserting the pure-program upper bound.
