# Instructor solutions — source-selected failures and data-acquisition decisions

**1.** delta_0(G)=(8/5-2/5)/2=3/5. delta_1(G)=-2/5, delta_R(G)=8/5. The difference is -1, equal to (m/pi_0)(delta_1-delta_R)=(1/2)(-2/5-8/5)=-1. The G success mechanism is unchanged; the observed eligible population now consists only of hard cases.

**2.** Initially delta_0(B)=(-7/10+13/10)/2=3/10, so G beats B by 3/10. On remaining hard failures delta_1(B)=13/10 and delta_1(G)=-2/5; B beats G by 17/10 per eligible failure. On the initial population this contributes (1/2)(13/10)=13/20. Neither downstream success rule was altered; conditional choice changed because source x1 qualified easy jobs and screened failures.

**3.** The diagnostic permits G on easy for 2-2/5=8/5 and B on hard for 2-7/10=13/10, averaging (8/5+13/10)/2=29/20. Paid x1+body yields 1+13/20-3/10=27/20, so the diagnostic wins for diagnostic cost strictly below (29-27)/20=1/10, ties at 1/10. The diagnostic changes information/action choice, not initial qualification.

**4.** Shared learning, operators and customers create between-nominated-robot interference, so robots are not independent policy-closed units; randomization must be at the union of all potentially affected systems or causal independence must be justified. Comparing only failures conditions on a post-x variable and selects different populations; retain all pre-x original orders, record x-specific pass/fail rates, and compare complete source-policy outcomes or approved within-source second-stage assignments. An observed robot success is not physical authorization.

**5.** Partition F_0 into F_1 and R disjointly. E[1_{F_0}g_a]=E[1_{F_1}g_a]+E[1_R g_a], then divide each term by its probability; rearrange. If the source changes future recoveries, occupancy, resource allocation or the later learned controller, g_a(z) depends on x, so one common integrand no longer exists and the partition alone does not prove a transportable delta.
