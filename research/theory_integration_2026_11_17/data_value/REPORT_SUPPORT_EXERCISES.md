# Student exercises — customer-conditioned target report support

1. Prove the rectangular unknown-row maximin expression for a stochastic report policy. Give an example in which coupled missing rows prevent simultaneous minima.
2. Prove the maximum value of certifying one exact missing row is bounded by pre-action opportunity probability times whole-service contribution span. Explain why this need not equal expected return from purchasing labels.
3. For hypothetical S=(3/4,3/4), G=(3,-1), T=(4,-6), F=(0,0), prove maximin value 1 when high-state P(report h)=3/5 and the low row is unknown, including *randomized* contingent decisions.
4. If the low row is exactly certified as P(report h|low)=2/5, calculate the optimal reported service map and value. What had been the *uncertified* worst-case value of that map?
5. Give three confusion matrices with pooled accuracy 3/5 but different optimal qualified customer-production value. Name the pre-action commercial labels needed to distinguish them.
6. Distinguish technical source-copy transfer, paid target report calibration, physical target grounding and an alternative embodiment in a prospective rights-cleared whole-customer-network design.
