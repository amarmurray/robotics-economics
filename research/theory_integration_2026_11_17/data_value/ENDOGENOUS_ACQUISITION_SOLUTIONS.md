# Instructor solutions: producing versus learning deliberately

1. For alpha≥1/2, select the specialist matching a usable report; expected future settled paid output is alpha, with R as fallback. J_P=r+3/4, J_D=1-1/8=7/8; P weakly wins iff r≥1/8. Forgone service is already the r gap, so subtracting r as an extra D charge counts it twice.
2. With only A and R, select A for a perfect report of A (mass 1/2) and R for reported B (mass 1/2): future value (1+1/2)/2=3/4; D total 5/8. With both specialists but no lawful report use, pooling A/B yields 1/2; stored data fidelity is economically unusable at dispatch.
3. Without grounding, both source settings yield 1/2. With grounding, low- and high-accuracy settings give 1/2 and 3/4. Cross-difference = 1/4. It is a qualified-menu × information interaction, not an intrinsic technical source interaction.

Differentiate the expected immediate reward and kernel for a fixed contingent legal policy; recursively propagate future value derivatives to get the sum over full-network histories weighted by its own occupancies. If the finite legal policy set is independent of x, right derivative of max policy values equals the maximum derivative over currently optimal policies. Hard safety thresholds, a new embodiment or rights revocation alter the policy set and invalidate naive differentiation across the jump.
5. Set the offered denominator before P/D choice and count no-orders, failed/refunded services, time/resource displacements and all subsequent settled revenues and newly trained tasks. Link every source to legally usable reports, qualified checkpoints and network exposure. Success-only cohorts condition on treatment-dependent events, so cannot identify comparative full-policy economic value.
