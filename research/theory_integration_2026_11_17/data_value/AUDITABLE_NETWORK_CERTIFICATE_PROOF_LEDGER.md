**Cut condition.** In a time-unrolled structural transition model, hold one full exogenous innovations vector fixed. Suppose an intervention changes only a specified source node. If all directed time-respecting paths to some downstream variable pass through structurally disabled edges, induction along the topological time order proves equality of that variable in the two intervention worlds. This fails if hidden common update, shared dispatch or market substitution nodes have been left out, or if a changed embodiment/action adds a new edge. Statistical absence of correlation neither proves a zero nor constructs the joint C1 coupling.

For two additional unbudgeted discrepancy paths C and M, P(C or M)≤min(1,q_C+q_M) by union bound. Conditional on a whole-service loss ≤3 if either event occurs, extra expected loss ≤3min(1,q_C+q_M). It also assumes every old influence allowance remains valid for the new architecture and c does not hide additional performance changes. The critical q with c=0, one path is (67/4000)/3=67/12000; at equality no strict certificate. For both q values .002, serial lower is 7.09675−3(.004)=7.08475. If the specialization difference varies with θ, the same inequalities must hold **for every θ** and the specialist upper must be valid for that same θ; do not compare independently optimized different-world endpoints.

**Exact one-sided binomial inversion.** In a fixed predeclared stratum, if E_i are iid Bernoulli(q) and none occur in n trials, P_q(observe all zeros)=(1−q)^n. Inverting the test gives an upper U=1−α^{1/n} with coverage≥1−α for this zero-event sample outcome. For K cells, replace α by α/K; by union bound all covered cell parameters lie under their bounds with coverage≥1−α. With a strict target q<ε, the minimum integer satisfying U<ε is floor(log(α/K)/log(1−ε))+1 (check boundary), yielding 536 at K=1 and 783 at K=4 for ε=67/12000, α=.05. This is conditional on a proved event dominance relation connecting E to the coupling error; the data event alone is not sufficient.

**Unsupported-history impossibility.** Consider observed policy class visiting h0 only, proposed policy reaching h1. Define two structural laws with identical transition/observation kernels on all reachable h0 histories, and identical all observed data. Under the first, cross-site influence at h1 is zero; under the second, a global controller update at h1 deterministically changes B accepted-service state. Both are observationally equivalent under the audited experiment, yet yield q_* 0 versus 1. No statistic based only on h0 logs can give a nontrivial uniformly correct bound on q(h1) without extra restrictions. Thus even arbitrarily large incumbent-only experiments cannot make the desired robust certificate.

**Physical admission rejection.** A positive-probability rare simultaneous two-operator recovery makes a route inadmissible under a hard B=1 requirement unless an independently verified reservation plus safe-stop policy prevents that state. No concentration interval certifies deterministic pathwise feasibility. The token invariant in the preceding proof ledger is a premise-plus-induction, not hardware evidence.
