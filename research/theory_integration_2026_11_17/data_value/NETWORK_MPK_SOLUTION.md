# Solution
Serial: baseline throughput 2 under both programs (value 6). Extra first-stage capacity earns 0 before, 3 after learning. Parallel: throughput 2 then 3 (value 6 then 9); extra incumbent route capacity earns 3 before, 0 after. The common minimum-cut slack, not utilization, governs the marginal. In the two-date model P gross marginal =3; G gross marginal =3+0.8*3=5.4. Net after capital cost 4: -1 and +1.4. This assumes lawful retained evidence, a supported learning rule, unchanged costs and demand, and no other coupled capacity. The final learned contribution is already counted. With a shared operator, multicommodity paths or joint-input assembly one must return to the full dated feasible recipe model.
