# Student exercises — auditability of production value under network interference

Use the [conditional chapter](AUDITABLE_NETWORK_CERTIFICATE_THEORY.md). Do **not** confuse exact synthetic arithmetic with real robotics measurements.

1. A staged, independently *assumed safe* route has J lower 7.09675 and a competent specialist has J upper 7.08. An omitted B loss has maximum whole-service magnitude 3 and probability q. Derive the strict q certificate threshold. What changes if the new isolation process costs 0.01 captured units?
2. Source trajectories are frozen from controller dissemination, but customer pricing shares a common marketplace with B opportunities. Can q_C=0 certify q_M=0? State the missing premise and show the conservative unknown-demand bound.
3. Derive a one-sided confidence upper for an iid Bernoulli trigger given zero events from n predeclared matched audit exposures. With four predeclared supported cells and simultaneous 95% coverage, calculate the minimum n *per cell* to cross the threshold from Exercise 1 when c=0.
4. Explain why 783 ordinary independent customer task successes or 783 episodes from one globally updating controller cannot automatically implement the binomial certificate. Specify the logically required event and dependence/coverage assumptions.
5. Construct two laws agreeing on all retained-policy histories that disagree on whether a new-body globally shared checkpoint damages B accepted service. What would distinguish them without deploying an unsafe new-body control?
6. Explain how a completely valid average captured-value statistical certificate can coexist with violation of a hard simultaneous operator capacity of one. Which engineering invariant is independently required?
