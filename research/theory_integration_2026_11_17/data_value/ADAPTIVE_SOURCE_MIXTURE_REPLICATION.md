# Replication — adaptive evidence source choice

23 November 2026. The companion JavaScript script is self-contained and deterministic. It enumerates the **11 exact twentieth-grid common laws**, evaluates the two legally admissible committed F-contingent T-audit policies, a known-law optional-audit oracle, and the independent embodied E benchmark.

Run from this directory using Node 20+:

\`\`\`sh
node adaptive_source_mixture_exact.js
\`\`\`

The script prints the full rational-grid results and throws on failed consistency, payoff, or policy assertions. All values use exact integer counts with denominator 20 or 80 until JSON presentation. An additional independent \`fractions.Fraction\` check was executed on 23 November over the same 11 laws; it verified endpoints, the source-mixture hedge, and the oracle minimum. The script does not calibrate any robotics transfer, customer margins, worker behavior or actual causal intervention. No full-repository CI was executed as part of this tranche.

The proof of the general four-cell identity is algebraic, not inferred from the enumerator. The synthetic table assumes the first-source F is already legitimately held, the second T source costs 1/10 in expected paid contribution whenever used, no unreported competitor output, and only one preselected qualified end-market architecture per cluster. If the two customer recipes can both be used freely, or if acquiring T changes customer or worker kernels, solve that expanded joint feasible plan instead of treating the reported rankings as portable.
