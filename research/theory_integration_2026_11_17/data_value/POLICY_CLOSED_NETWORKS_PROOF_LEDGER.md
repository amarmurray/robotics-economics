# Proof ledger — policy-closed interference and complete qualified-production comparisons

**18 Nov 2026; conditional mathematics, not a validated robot deployment.** The [theory](POLICY_CLOSED_NETWORKS_AND_DATA_VALUE.md) extends the existing SS1–SS3 and causal influence chapters without replacing their prior results.

**A. Definition versus certification.** For all approved complete policy assignments and maintained persistent regimes, a policy-closed graph includes every potential directed cross-unit assignment-sensitive causal dependence of controllers, demand/dispatch, operator availability and accepted service over the full horizon. If a directed path across a proposed graph cut exists under any approved assignment, the cut is invalid. Merely observing no status-quo message, or statistically insignificant correlation, is not evidence of a counterfactual no-path restriction. An *overinclusive* graph sacrifices possible independent units but not treatment consistency. An *underinclusive* graph risks interference bias.

**B. Conditional component consistency.** A time-ordered structural induction: initial component-local response to own assignment holds by assumption; if it holds through t, the t+1 component variables have no assignment-sensitive parents outside the component by graph closure, so they remain unchanged by other components' assignment vector. Induction delivers \(Y_C(z)=Y_C(z_C)\). Correlated outside exogenous shocks do not imply policy interference; if outside policies alter those shared shocks, they are endogenous paths and must be included. This argument assumes fixed structural scope, known true complete influence pathways and no hidden global model reset; it is a conditional causal lemma, **not** an algorithm that discovers the true graph from logs.

**C. Unbiased full-policy HT.** For fixed potential outcomes conditional on all exogenous inputs, \(E_Z[{\bf1}\{Z_C=p\}Y_C(Z_C)/\pi_{C,p}]=Y_C(p)\) by random assignment with positive probability and consistency. Likewise for q. Subtract and sum. Randomization across clusters with common noise can preserve unbiased expectations but not simple independent-observation variance; network assignment is invalid if q's dispatch changes p-assigned components. Fixed pre-action enrolment preserves a common denominator. It estimates a *mean* effect only, not a regime-wise min, total-effect copula, adaptive reassignment limit or hard safety property.

**D. Fully randomized selective policies versus SS2.** Suppose a selective policy makes eligible A use G and excluded B use F, but shared demand, operator and checkpoint paths may change B outcomes. Eligible-only G-vs-F assignment identifies the *A* effect under a fixed exposure environment; SS2's total equals A only if B's complete outcome and A's environment remain unchanged under the selective contrast. Randomizing two **whole-network safe policy masks** on independent policy-closed network components instead identifies \(E[Y(H_G)-Y(H_F)]\) directly, including actual B consequences. No cross-world diagnostic or presumed \(\Gamma=0\) is needed for the **mean**. When only one connected market exists, single-horizon treatment provides no replicated unbiased point estimate of both alternatives; this is an identification limit, not a computational shortcoming.

**E. Two-unit sharp interval.** Under F, A=5, B=5. Under candidate, A=7. If unknown B outcome lies [0,10] and new candidate implementation cost is exactly 1/2, global difference is \(7+B-1/2-(5+5)=B-7/2\), so [-7/2,13/2]; both endpoints are feasible unconstrained complete response laws with identical observed A gain. Verified isolation implies B=5, yielding +3/2, but an isolation claim without reachability/customer evidence does not. A *different* shared policy with no isolation cost and B=1 has -2, with B=8 has +5. Do not use the costed bound to misdescribe the distinct cost-free shared policy.

**F. Four-network exact assignment audit.** F totals [10,10,10,10], shared G totals [8,15,8,8], cost-inclusive isolated G totals [23/2,23/2,23/2,23/2]. Full mean contrasts: shared-minus-F=(39/4)-10=-1/4; isolated-minus-F=(23/2)-10=3/2; shared-minus-isolated=-7/4. A-side F=5 and G=7 throughout, so the A-only +2 sign does not determine the full network sign. For each of the 16 vectors \(z\in\{0,1\}^4\), compute \(HT_G(z)=\frac14\sum_i2z_iY_i(G)\), \(HT_F(z)=\frac14\sum_i2(1-z_i)Y_i(F)\). Averaging all vectors gives 39/4 and 10 by pairing each unit with eight treated and eight control assignments; arithmetic code independently enumerates the vectors. This illustrates unbiased assignment expectation, not a practical sample-size guarantee or robotics field observation.

**G. Optional data value and incompatibilities.** If the old admissible policy set remains a subset under free, optional source-data access, the supremum over the larger set is weakly larger (and so is the maximum of a common fixed maximin criterion). If an ML update must be broadcast, an old policy is removed, curation consumes resources, or the customer demand/rights environment changes, the subset premise can fail. One forced-training failure cannot establish negative option value of optional free data. The only economic payoff is the same complete customer-service production value, counted once.
