1. For legal common actions a,b, ex-post minus pre-report production is L=p(d_A)_++(1-p)(d_B)_+ - (p d_A+(1-p)d_B)_+. Both signs agree outside [alpha,beta], so L=0 there. Inside it is min{p(theta-alpha),(1-p)(beta-theta)}. The crossing is theta*=p alpha+(1-p) beta, and its height is p(1-p)(beta-alpha). This is a conditional paid-Q identity, not a benchmark performance estimate.
2. Segment: L(theta)=min{theta/2,(1-theta)/2}, so the maximum 1/4 is attained at theta=1/2 and both endpoints return zero. Rectangle allows the impossible simultaneously extreme d=(1,-1), giving 1/2. Endpoint-only search misses the common-factor internal information optimum.

Entirely forbidden/uncertified Q entries must not enter the feasible set.
