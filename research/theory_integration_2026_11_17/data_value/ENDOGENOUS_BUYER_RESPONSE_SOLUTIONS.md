# Instructor solutions (separate from student exercises)

1. max(2D,3C)=2D+3C-2DC, so V_G=2p_D+3p_C-2x-K_G. Q_G=1 is merely eligibility; the overlap event determines which accepted order is displaced. Baseline R with Q_R=0 pays 2p_D.
2. Draw independent D,C_R each fair, then an independent uniform U; set C_G=1{U<=2x} if D=1 and C_G=1{U<=1-2x} if D=0. All conditional probabilities lie in [0,1], giving one joint law. R pairs stay independent; G buyer marginals each equal 1/2 and G overlap is x. The exact integer code chooses x=k/20.
3. x_G in [1/10,2/5], yielding G in [17/10,23/10]. E=21/10 is maximin, and P=2 and G_serve=31/20 are dominated in this toy. For G lottery q, regrets at G-high and G-low are (1-q)/5 and 2q/5; equality gives q=1/3, worst 2/15. No G assignment means delta and G values cannot be estimated from R. The cap itself requires a justified mechanism or prospective G evidence.
4. Add and subtract the qualified-G payoff under baseline original buyer offers: (E_R f(Q_G)-E_R f(Q_R))+(E_G f(Q_G)-E_R f(Q_G))-K_G. Pre-offer no-anticipation, unchanged buyer-facing terms/interference and independently verified rights-safe Q_G/physical availability make the second term zero. Full paired original offers and no-offers are still required, not successful invoices alone.
5. A lawfully assigned full-policy trial with complete cash/resource settlement identifies each policy's expected total contribution under the randomized cluster population (subject to exchangeability and interference conditions). It does not identify how many losing original offers existed or the value of other counterfactual t1 dispatch/qualification menus without additional observation and transport assumptions.
