# Exact replication — transported report calibration

This is a scoped **synthetic mathematical illustration**, not an actual robotics trial, economics calibration, independently reviewed result or full-repository CI.

Run with Node.js 22 or other supported modern Node with BigInt:

    node signal_kernel_transport.js

The executable verifies 76 exact assertions (rational end points, every one of sixteen deterministic report decisions in the minimax check, and a 61-point rational accuracy grid for the analytical envelope) and emits JSON. The output was saved in signal_kernel_transport_results.json with a terminating newline. Both have content-identical Git blobs to the locally executed files (source e4eef2b88feeec0503590816d68d8857e36c9c32 and result 19951a901f6afdd6d71a9908c9f7d9c9bd0a646f). An independently formulated Python fractions calculation checked five principal identities. Source and record are deterministic. Exact arithmetic supports the worked counterexample but is not a proof of the general conditional-TV theorem; see SIGNAL_KERNEL_TRANSPORT_PROOFS.md.

The two accuracies 3/5 and 9/10, complete qualified contributions, prior weights, report labels and independent physical approval are all assumed by construction. Neither report has been validated on real target customers; no real controller/dispatcher/operator original-order dataset exists here. The general theorem requires a fixed qualified service menu and population; real learned occupancy and recovery may violate that setup. No historical full package, numerical BEA–BLS industry matrix, physical experiment, or independent peer review was executed.
