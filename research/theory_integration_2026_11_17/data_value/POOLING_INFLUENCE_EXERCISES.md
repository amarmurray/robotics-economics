# Exercises — whole-network economic source-influence certificate

Work with the qualified original-buyer accepted-and-paid objective, not task accuracy. Every number below is **synthetic**. Solve before consulting the separate solutions.

1. For H={F,T,M}, prove D(H)=D2+theta_D(H). Why do source-conditional payoff interactions differ from interactions in the latent technical qualification score?
2. State the common-policy and reward conditions needed to couple a full recursive learner/operator/customer Markov process to a two-local reference. Prove the finite-horizon 1-product(1-delta) upper mismatch probability. Explain precisely when taking sup over policies preserves the value difference bound.
3. Suppose every coalition has reference economic dividend theta0(H)=0 and conditional complete-horizon TV bound 0.01 for each of SG and E with reward width 1. Obtain a rigorous target SG-E interval from measured D2=0.26. Can one improve the coefficient 8 just by assuming free-source value monotonicity?
4. Recompute when all lower source coalitions are architecturally identical to reference and only triple has each-program bound 0.01, with D2=0.40. What would have to be observed to justify the stronger assumption?
5. A model evaluator finds no cross-source effect at empty data and every pair, but a global checkpoint is rebuilt when F,T,M all appear. Is it valid to set the conditional TV delta to zero? Give a counterexample with an original-buyer paid outcome.
6. Contrast an independent learner/operator island with the actual all-network pooled target. Specify a prospective evidence and rights manifest that distinguishes valid target-scale source-comparison data from a missing customer-paid or embodiment arm.
