# Exercises: resource incidence and economic data value

1. Derive (1) from weak duality for binary recipes. Why must the old relaxation gap be included?
2. Prove (2) for a common structural menu, and explain why newly admitted recipe labels require a different bound.
3. In the two-date example compute the optional G value when P(L=Q)=2/3. Compare X and E. Then impose a one-slot parent cap.
4. Suppose L is unobserved before dispatch and each state has positive conditional probability. Can A and B be combined under pathwise capacity without fallback?
5. For p_Q=3, show that U_0 and U_1 equal the optimal values for both alignment states. Explain why this is not a wage estimate.
6. Give an example where a positive aggregate worker release cannot fund any new customer service, and state an audit that distinguishes it from successful alignment.
