# Proof and falsification ledger — signal disclosure vs controller admission

**Scope:** finite qualified continuation menu, common pre-source original customer population, net complete service outcome. No field validation, safe deployment authorization or scientific novelty claimed.

1. **Blackwell optional information:** let signal S1 Blackwell-dominate S0 with garbling kernel T(S0|S1). For any randomized S0 policy, a planner observing S1 can simulate S0 using T and take the same admissible action. Expected payoff is identical because the report is economically/physically inert except for selection and the old policy is feasible. Supremizing gives W(c,S1)>=W(c,S0). If signal costs, mandated interventions, changed customer orders, new observation load or safety-rule restrictions enter, this comparison may fail after costs or because the old decision rule is unavailable.
2. **Interaction:** the four-term identity Delta=W11-W10-W01+W00=(W11-W10)-(W01-W00) holds by algebra. It does not identify a unique share of data value attributable to learning vs information, nor a natural mediated effect. Both interventions and the shared report kernel must be physically implementable to label the mechanism controlled.
3. **Exact baseline:** prior high 1/2, action net values F=(0,0), S=(3/4,3/4), G=(3,-1), T=(0,-6). W00=1; W01=(3+3/4)/2=15/8. With posterior p, G payoff 4p-1; it beats S iff p>=7/16. A symmetric report q has posteriors q and 1-q, yielding q threshold 9/16 and W0(q)=2q-1/8 above it.
4. **Substitute:** source-trained G=(3,1) has conditional mean 1+2p, beats S, F, T for all p in [0,1]. W10=W11=2, so Delta=0-7/8=-7/8. This is an economic return table, not a claim all attempts can safely succeed.
5. **Complement:** source-trained T=(4,-6) has conditional 10p-6. It exceeds G at p>5/6 and does not beat G without informative conditioning. For q<=5/6 its signal arm has same value as baseline (given q>=9/16); for q>5/6 W1(q)=5q-21/8. Thus Delta(q)=max(0,3q-5/2) for q in [1/2,1]; exact endpoint Delta(1)=1/2.
6. **Paid combination:** with source+admission cost 3/10 and signal cost 9/10, retained W00=1, signal alone 15/8-9/10=39/40, learned controller alone 1-3/10=7/10, both 19/8-6/5=47/40. For q>5/6, joint exceeds retaining when 5q-21/8-6/5>1, i.e. q>193/200. Equality at q=193/200. No other q interval can win under these costs.
7. **Identification:** if independent, physically approved full-network randomization identifies W arm policy means under consistency, positivity and interference isolation, the four-term policy interaction is identified. Mechanism separation needs the report kernel held stable, controlled controller admission and stage-two/technical qualified support. Post-failure conditioning across different sources is selection, not cross-world causal stratification.
8. **Unsupported cell:** if only W11 has justified endpoints [L,U], substitute them linearly into Delta to obtain a valid outer interval. Sharp only if endpoint whole-network response laws are jointly attainable. No expected contribution is assigned to an unapproved policy.
9. **Alternative explanations:** a stronger qualified specialist, free routine-data report, natural controller-recovery adjustment, cheaper target-only body, changed visited-state law, endogenous customer orders or policy-driven diagnostics may erase the joint purchase. Match the actual source, horizon, original orders, operator safety and resource costs.

**Closest prior art:** Blackwell (1953), Murphy (2003), Stensrud et al. separable interventions (different domain), DDA §5/App B, standard optimization/factorial identities. Originality unverified.
