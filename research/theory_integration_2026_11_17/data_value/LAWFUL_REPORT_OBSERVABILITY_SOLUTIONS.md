If h1,h2 have disjoint Bellman-optimal action sets, its positive-mass regret cannot vanish. Merely adding output labels never partitions an atom; the unrestricted two-symbol oracle can be infeasible.

2. W*=1. For z=(0,0,1), the first two contexts yield only one paid unit total, and the last one yields one; W=2/3. A new lawful signal z'=(0,1,0) separates h2 and groups h1,h3 so W=1 with two labels. The field must exist, arrive before dispatch, be lawful to use, and not unexpectedly change Q; no such field is empirically established. E=3/4, so coarse SG−E=−1/12; fine gross SG−E=1/4.

3. The gross signal improvement is 1/3 and net improvement is 1/3−1/8=5/24. Fine SG net=7/8, fine SG−E=1/8. Costs and paid Q were stipulated solely for a transparent counterexample.

4. Each label cell chooses a common physically/legal action. Any L-label rule uses ≤L action identities, bounding its return by selecting the best of those actions on each atom. Conversely, assign each atom its best among a chosen ≤L-subset and output that identity. If M(h1)={a} and M(h2)={b} but z(h1)=z(h2), M_{B}=∅ and no legal z-measurable dispatch exists until information or available actions change.

5. Each regime's separate optimum earns 1 and its own regret 0. A deterministic hidden-regime rule has worst regret 1. With a randomized probability t of a, regrets are 1−t in regime A and t in regime B, minimized at t=1/2 giving 1/2. A lawful timely signal revealing θ yields 0, if using it does not change the outcome law.
