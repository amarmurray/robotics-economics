# Replication and interpretation

Run the committed standard-library-only file with Node 18+:

~~~sh
node postservice_response_exact.js
~~~

It enumerates all 4-atom original A/C order kernels with masses in quarters and total variation at most 1/4 from the uniform R kernel. There are 13 feasible kernels for each free-worker history and 169 paired G response laws. It independently verifies the common-law output interval [87/80,177/80], R transport value 33/20, two-job worker conservation, fixed R/P/E alternatives, no oracle action, exact minimax policy G-early 1/10 versus E 9/10 and worst regret 81/800. Source is a function whose body was executed in the same JS V8 tool call that created the blob. A separate Python Fraction enumeration over the identical 13x13 rational grid recovered the endpoints and policy. These checks establish arithmetic, not identification or field magnitude.

Atom ordering is 00,01,10,11 for A potential interest and C original order; each state-conditional R atom has weight 1/4. Physical G early H probabilities are good=1/2, idle=1/4, blocked=1/4, with good accepted early A paid receipt 4/5. The blocked state contains **two distinct repair jobs** and a worker who can clear only one. The selected-report counterexample changes only the original C offer in the R-good history while Q_R=0, so all R paid invoices remain identical. The strong conditional invariance K_G=K_R is assumed, not inferred.

**Sharpness versus outer bounds:** equation (5) in the manuscript is generally conservative. Here its endpoints are attained by shifting exactly 1/4 of a feasible original-buyer atom from the worst to the best paid service in each free-worker stratum. The numerical grid checks all rational quarter-mass candidates only; the proof in the manuscript covers the continuous TV ball at δ<=1/4.

No paid commercial data, BEA coefficients or actual G action support are contained in this reproduction. The latest retrieved official BEA sources describe supply/use tables and the API, without implying we obtained numeric cells.
