# Exercises: decision-sufficient robotics program evidence

These are synthetic models, not actual robot data. Work from [the theory](DECISION_SUFFICIENT_EVIDENCE_AND_PROGRAM_CHOICE.md); answers are in a separate [instructor file](DECISION_SUFFICIENT_EVIDENCE_SOLUTIONS.md).

1. For independent admissible customer/operator/learner clusters and partial identification a∈[-1,5], b∈[3,5], derive the minimax regret and ex ante SG allocation p when randomized cluster assignment is lawful. Repeat when only a single deterministic program can be chosen.
2. An idealized lawful test reveals the exact complete SG average accepted-paid outcome a (not task qualification alone); another reveals b. Derive the worst **postreport** minimax regrets for both tests, with and without randomized cluster allocation. Decide which to run if normalized test costs are c_A=1/2, c_B=1/8, and there is no Bayesian prior. Explain why this is not an expected money return on information.
3. Fix Pr(fully qualified)=Pr(original eligible buyer willing)=1/2. Construct two joint distributions with opposite SG-vs-E ranking, where SG=12Pr(qualified AND buyer willing AND paid)−1 and E=4. Explain whether perfect measurement of task qualification alone identifies the economic decision.
4. Explain which records and valid intervention unit would distinguish S as an added optional source archive, G as target-grounded training, and E as an embodiment investment when current production also generates future training data. State how original buyer outcome and continuation are counted without duplication.
