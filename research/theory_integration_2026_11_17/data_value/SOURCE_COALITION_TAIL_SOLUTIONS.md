# Instructor solutions: source-coalition tails and transport

1. D(FTM)=D(FT)+D(FM)+D(TM)-D(F)-D(T)-D(M)+D(empty)+theta_D(FTM). The last term is the third finite difference, identified only with the complete triple program outcome or a valid structural restriction, never from singleton/pair contrasts alone.
2. Optional gross value at FTM is at least max observed pair=2.5; independently defended capacity cap=3.5 gives each program [2.5,3.5], so SG-E is in [-1,1] under rectangular completion. Opposite extreme completions respect monotonicity. A stricter separately justified lower 2.7 narrows to [-0.8,+0.8]. Pair observations alone predict 3.2 for each but say nothing about the third difference.
3. Threshold: singles/pairs zero, triple 8, so dividend +8. Capacity: J(empty)=0, single=1, pair=2, triple=2: 2-6+3=-1. Both have additive technical source counts; market qualification/payment/rationing induces higher-order economics.
4. For a subset T containing a source outside H_i, pair each summand U with U union {t} to cancel in theta_(f_i)(T). This applies to each i and the cost if it is order<=2. Shared learner/checkpoint or operator constraints couple otherwise separate f_i and invalidate the sum decomposition.
5. Island mean=(3+0-3)/3=0. Target mean=(3/2)+(0)-3/6=+1. Reweight only if conditional complete-buyer paid means and source exposure policies are stable and target original eligible buyer class exposures have experimental support; global training/operator interference invalidates the additive formula.
6. Direct randomized assignment of complete physically and legally closed, independent whole learner/operator/buyer network replicas to fully pooled SG or E; collect original eligible buyer accepted and finally settled paid contribution, costs and interference. This identifies the supported *program contrast* without estimating all coalition dividends. If E triple is disallowed, mark it unobserved; report bounds/alternatives, do not assign it zero or extrapolate from pairwise experiments without a justified economic tail bound.
