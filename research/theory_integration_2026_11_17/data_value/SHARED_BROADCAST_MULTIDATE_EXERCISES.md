# Student exercises — adaptive shared-learner data value

All exercise returns are hypothetical accepted-and-paid normalized contributions, not observed robot dollars.

**1.** Derive equation (1) for two qualified/accepted original buyer services v1>=v2>=2 with a single shared recovery slot. State when it fails.

**2.** At date 0 a program generates L; at date 1 L and licensed W are observed. Only if L=1 may the firm pilot B with current net 3/4 instead of R current net 2. At date 2 R pays 2, or either new site pays 4 with a free shared operator. Derive the dynamic expected optimum without conditioning date-1 action on unobserved future orders.

**3.** Conditional on L=1 both sites have marginal paid eligibility 3/4, shared operator independently free 3/4, and Pr(L=1)=1/2. Construct maximally synchronized and diversified site joint laws, compute the optimized P value and rank it against full independent E value 65/16. What additional observation is needed if worker availability depends on the two sites' failures?
