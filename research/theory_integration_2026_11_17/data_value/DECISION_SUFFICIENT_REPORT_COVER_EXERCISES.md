# Exercises: decision-sufficient reports for qualified robotic production (student edition)

All settings are synthetic, finite, original eligible-buyer paid contribution units, not robot benchmark dollars. No answers here; see instructor-only file.

1. **Three-way conflict.** Three equally likely original-buyer histories have legal paid-optimal action sets {a,b}, {b,c}, and {a,c}. An action pays 1 if optimal and 0 otherwise. Compute the best one-symbol paid value, the fully observed value, and the smallest sufficient report alphabet. Why does a pairwise conflict graph fail?

2. **Minimal-report theorem.** For arbitrary positive p_h, legal M(h) and whole-horizon q_h(a), show that zero-regret partitions correspond to coverings of histories by sets F(a)={h: a is lawful and paid-optimal}. Prove the minimum number of report outcomes equals the smallest optimal-action set cover. Specify the assumptions under which this report may not be physically obtainable.

3. **Joint report fields.** Let x,y be independent fair bits, both predecision legally observable. Choose a or b; a pays one if x XOR y=0, b if x XOR y=1. Compute W(no report), W(x), W(y), W(x,y), and the finite report-field cross-difference. Explain why this does not disprove diminishing returns in an oracle set of action labels.

4. **Dynamic falsifier.** Identify at least two mechanisms by which acquiring a customer/physical-context report at t=0 can alter future history occupancy or lawful menus, making the fixed report-cover oracle insufficient for an SG versus E investment comparison. Give the minimal original-buyer, operator, rights and fully cleared production evidence needed to study each mechanism.

5. **Oracle action-budget submodularity.** With a common safe legal baseline action a0, prove that the additional paid value of making extra action labels selectable through a perfect exogenous report is monotone and submodular in the set of additional actions. Explain what fails when training data changes qualification or buyer demand.
