# Exercises — shared reserve and controller learning

1. For premiums (4,2,-1), compute the first and second slot gross values and a price certificate for one slot. Show why an isolated sum is an upper bound only in the additive or nonpositive-interference model.
2. In the chapter's pooled G model, derive the feasible interval for j, the expected total calls, and G+K net contribution. What can be inferred from identical isolated call premiums?
3. Show that pointwise deletion of positive premiums implies weakly decreasing order statistics. Does lower expected call count alone imply this? Explain using both G worlds.
4. Suppose only a two-call joint recipe pays 3. Is reserve value discretely concave? What additional evidence is needed before using the additive price certificate?
5. A model approximates next-stage joint value within epsilon by additive component functions. Prove why a difference of two action continuations can cost up to 2 beta epsilon in the transport bound; explain why free optional data does not necessarily lower the optimized value, even when a committed intervention is unprofitable.
