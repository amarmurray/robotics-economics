# Prospective controlled mechanism audit — no trials performed

**Unit:** entire policy-closed controller-learning/dispatch/operator/customer-order network, with original prospective order universe frozen before any source decision; no individual robot rollout or accepted-order-only denominator counts as an independent unit. Acquire physical/customer approval independently of this plan.

| Intervention variable | Controlled implementation | Minimum integrity check |
| --- | --- | --- |
| Source data snapshot | Versioned mix of autonomous field, failure/recovery, teleoperation, deliberate target probe, simulation, synthetic/public/pretrained inputs, distinct rights/curation and costs | Immutable hash, training/exclusion ledger and supported state strata |
| Controller admission C | Existing physically qualified policy C0 vs separately safety-approved target-qualified C1, frozen model/version and retained old-policy escape | Disclose resource/operator capacity, new embodiment eligibility, jointly accepted target service |
| Report I | Fixed nonactuating report generator K run on same authorized snapshot; display vs withhold while retaining allowed old action | Matched commercially relevant state labels, source-conditional error/calibration, time of reveal, no control-plane leakage |
| Continuation policy A | Pre-approved qualified fallback/specialist, grounding G, changed-body T only when independent body/control qualification exists | Conditional randomization within report-eligible histories, precommitted full operating policy |
| Outcome | Every originally prospective customer order plus new/declined/displaced/expired orders, value captured, recovery, operator/dispatch effort, outside option, all real cash costs | Whole-network net service J, not raw task accuracy or billable robot-hours |

Design: where *every* physical policy has prior signoff, randomize policy-closed networks across C×I four arms and, separately where feasible, pre-choice approved continuation actions; evaluate a prespecified report-dependent rule on held-out networks. Require identical baseline market populations or use a justified covariate transport target. Do not condition the arm mean analysis on failures induced by C. Randomize at learning/dispatch/operator/customer-market closure, with cross-network demand substitution audited; otherwise estimate the interference policy being run rather than claiming independent arm means.

Interpretation: arm means identify an average complete-policy interaction if the network design is valid. They identify a **pure information-versus-admitted-capability mechanism** only if report generation K, stage-one market opportunity and report noninvasiveness are verified, and if the controller admission is itself a distinct realizable intervention. Collect technical joint qualification Q, target occupancy, source-specific recovery and original-order economic response to test competing explanations. If a cell is approved but unsupported in data, use auditable full-service bounds; if never approved, remove it from the menu.

Failure modes: C1 changes who gets a high-state report; report visibility changes consumer orders/prices; hidden cross-site controller learning; shared operator capacity; report merely reclassifies failure; changed embodiment adds manufacturing delay; forced reporting triggers physical abort; free routine data provide the same signal; specialist wins economically. A zero observed safety event is not a proof of approval.

Current evidence status: no versioned C×I policy-closed customer datasets, no permission, no independent commercial signal labels, no actual trained C1 or body, and no real cost or outcome calibration.
