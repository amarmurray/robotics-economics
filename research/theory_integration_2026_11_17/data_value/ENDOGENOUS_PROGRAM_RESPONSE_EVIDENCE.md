## Discriminating measurements and limits
A complete audit of old R buyer Z and old/P queue Jp can test old R/P paid-service values, but **cannot** by itself estimate G-induced qualification QG, buyer order DG or G worker-clear FG when G is never attempted. Separate G marginals and all pairwise QG–DG, QG–FG, DG–FG tables are also insufficient for the example. Its missing estimand is the *joint* \(\Pr(Q_G=1,D_G=1,F_G=1)\), together with old-Z fallback overlap if Z is not independent. A valid prospective G-action study needs original eligible buyer/no-buyer records, target qualifications and operator jobs jointly linked within allowed rights, with payments, before/after actions and comparable connected-cluster assignment. Observational reweighting needs verified positivity and exchangeability; when either fails report bounds, not a point causal return.

If calibration is entirely offline and creates no physical recovery event, set the G-job kernel to zero **only when physically verified**, then revisit the production policy; do not import the synthetic queue distribution. Compare target-grounding using existing data against additional source collection, deliberate teleoperation, other data sources and new embodiment in qualified customer production, not benchmark percentages. Count later learning only through genuinely measured downstream paid production and never duplicate its continuation contribution.
