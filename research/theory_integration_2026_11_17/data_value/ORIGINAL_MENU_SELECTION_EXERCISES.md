# Original-menu selection and data-acquisition exercises (student version)

Assume the same two-order toy: V_G=7/2+(3/2)theta_N, V_E=9/2, V_R=4; G/E are hypothetically independently physically qualified, not actual certified robots.

1. In the complete high-budget parent frame, C response coverage is rho=3/4; respondents always accept C; nothing is observed for nonrespondents. A cross-menu bound epsilon=1/8 is independently assumed. Derive the sharp theta_N interval and compare G with E without pretending nonresponse equals refusal.
2. Construct two observationally equivalent worlds that agree on all respondent observations and the C solicitation denominator yet reverse the G/E ranking. Explicitly specify missing C and natural-menu population response.
3. Suppose an auditable lower bound u_L is obtained for the nonrespondents' C rate, with respondent s=1 known exactly. Solve the *strict* threshold u_L above which G robustly beats E. Why might more respondent-only data be less useful?
4. Assume independently sampled Bernoulli respondent/nonrespondent outcomes with n_R=n_U=400, observed fractions 1 and 1/2, joint alpha=.05. Derive simultaneous Hoeffding bands and the conservative natural-GG lower bound. State two reasons this is not a physical admission test.
5. Explain why neither a negative X fine-tuning experiment nor a positive C buyer survey proves a negative economic value for freely optional old data or a positive dollar value for G. Describe one admissible matched source-to-joint-qualification experiment.
