# Instructor solutions — keep separate from student exercises

1. For fixed stochastic policy the unknown row multiplies y_pi(s,z) linearly; a simplex minimizer places mass on the lowest y_pi. Independent unknown rows allow each minimizing report independently. Two rows with payoffs (0,1) and (1,0) but a required common row have joint payoff always 1 rather than sum of independent minima 0.
2. Certifying z changes the fixed-policy lower value by p(z)(E_K y_pi - min_s y_pi), a nonnegative number no more than p(z)R(z); compare maximized values via difference-of-maxima. Finite-sample costs, priors and possible reporter effects must be added to determine economic expected value.
3. The unknown low row includes conditional high-report probability 3/5, identical to the high row. Then report is independent of opportunity; any randomized conditional action induces an unconditional lottery of net whole-network action means F=0,S=3/4,G=1,T=-1, so none exceeds 1. Constant G guarantees 1.
4. Enumeration gives high-report G, low-report S, value 43/40. The same rule under arbitrary low row has minimum 22/40, so before certification a rational robust planner used G/G worth 40/40; the guaranteed-value gain is 3/40, not 21/40.
5. Conditional row pairs (P(h|H),P(h|L))=(1/5,0),(1,4/5),(3/5,2/5) have the same pooled 3/5 accuracy, but maxima (T,G;44/40),(G,S;47/40),(G,S;43/40). Need original customer order z (before report), reporter s conditional on z and accepted-service whole-network contributions.
