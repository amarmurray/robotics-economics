## Environment: a signal is only useful if an economically productive choice remains feasible

Let theta denote the original customer's relevant order/production regime and let A(D,h) be a finite set of **independently approved complete customer–robot–operator policies**, where D is the currently accessible/usable heterogeneous source inventory and h is installed, safely supported embodiment capacity. One policy is a complete robot/dispatch/recovery/customer-service plan; a model-weight file or a benchmark pass is not a member of A by itself. The retained incumbent R remains in the initial set only if it is actually physically and commercially feasible. Embodied candidates can be generated through learning from field trajectories, failures/recoveries, teleoperation, simulation, synthetic or public/pretrained information, but each route has different rights, inference kernels, real validation and costs. A newly conceived configuration is *not* an admitted policy until qualification and safety authorization.

A target-grounding procedure G may deliver a lawful, predecision report Y with kernel k_G(y|theta) (or change permitted observation/recovery). With original customer offer version, resources, receipts and operator terms held fixed for this conditional result, define gross optimized next-window value

    W(A,k) = sum_y P(y) max_(a in A) E[u(a,theta)|Y=y].

The payoff u is already contribution from safely qualified, accepted, completed, paid production against competent alternatives, after its operating resource costs. A one-parent operator can choose at most one complete action. A multi-customer network replaces the displayed max by the existing production-system V; there is no extra data premium. The timing above permits the action to be chosen *after* Y; if embodied manufacture, reconfiguration, customer terms or operator dispatch must be fixed before Y, the policy set must respect that earlier commitment.

Acquisition investment is evaluated in the SAME J, for example

    J_t = max_{a_t} { accepted current contribution(a_t) - actual costs(a_t)
                     + beta E[ J_(t+1)(D', h', omega', information') ] }.

Production-generated information, a target audit, controller acquisition, hardware lead times and changed customer demand enter the transition once. No continuation value is added again as an intrinsic dataset price.

## Proposition: source-to-policy and grounding can be complements or substitutes

For an unchanged theta distribution, signal experiment and original customer payoff law, let A0 be an admitted menu and A1 include A0. Let k0 be uninformative and kG an informative predecision experiment. Define the cross difference

    Gamma(A1,A0;kG,k0)
       = [W(A1,kG)-W(A1,k0)] - [W(A0,kG)-W(A0,k0)].

1. W(A1,k) >= W(A0,k) for each fixed signal, by feasible-menu inclusion. If kG Blackwell-dominates k0, W(A,kG) >= W(A,k0) for each fixed menu: the better signal may always be ignored or garbled.
2. **Gamma has no universal sign.** The information value of target grounding depends on which embodiment-specific recipes source data makes legally and physically available. Its source/target cross difference can be positive when training creates state-contingent options and negative when a robust generalist embodiment makes state diagnosis less necessary.
3. The original fixed-candidate derivative from Data Value Theory D1 describes smooth learning responses within a fixed candidate-qualification and joint-outcome structure. If data *creates a previously unavailable potential embodiment/recipe label* or changes feasible post-report timing, that derivative cannot by itself price the option. The finite difference J(D plus source)-J(D), evaluated with the new qualified action set and costs, remains well defined. This does not assert that the option-creation theory is new: it composes classical real-option/Blackwell choice-set reasoning with the already defined robotics production system.

**Proof:** For item 1, any policy available under A0 is available under A1; a decision maker observing kG can implement the k0-compatible decision by ignoring the extra information, provided the policy remains feasible. For item 2, the two constructions below obtain strict opposite cross differences under identical two-regime probabilities. Thus neither sub- nor supermodularity follows from nested menus and better information alone. Item 3 follows because a formula differentiating probabilities indexed by one fixed qualification set cannot account for a new decision label without enlarging that index/set (or adding a discrete state transition). These are conditional applications of standard finite decision mathematics, not a scientific originality claim. QED.

## Exact two-regime original-customer model: value lies in matching and actionability

Suppose theta=A or B with probability 1/2, all listed policies are independently physically approved under the SAME original customer terms, and the numbers below are *normalized captured contribution units* for one complete qualified paid service, not robot performance percentages:

| Complete policy | Original regime A | Original regime B |
| --- | ---: | ---: |
| Retained R | 2 | 2 |
| Target-specialist E_A enabled by source learning | 4 | 0 |
| Target-specialist E_B enabled by source learning | 0 | 4 |
| Independently qualified robust generalist E_0 | 7/2 | 7/2 |

A lawful, predecision binary target report Y equals the regime with symmetric accuracy alpha between 1/2 and 1. A source intervention X_single makes only E_A available on an already budgeted compatible specialist body; a paired/aligned source X_pair makes both E_A and E_B candidates. This is a **stipulated source-to-approved-policy map**, not evidence that either real source can do so. G supplies the report, not a guaranteed skill gain. E_0 is a separate independently qualified new body. When candidate embodiments require additional manufacturing/adaptation spending, charge it exactly once in J and retain the arrival-time constraints.

With the retained R option and a *flexible*, actually certified post-report choice of specialist policies:

    W(R)=2;
    W(R,E_A | alpha)=1+2 alpha;
    W(R,E_A,E_B | alpha)=4 alpha;
    W(R,E_0 | alpha)=7/2;
    W(R,E_0,E_A,E_B | alpha)=max(7/2,4 alpha).

**Derivation.** Given report A, the posterior A probability is alpha. The selected E_A earns 4alpha, E_B earns 4(1-alpha), and R earns 2. For alpha>=1/2 the selected E_A weakly beats R in report A; the symmetric result holds in report B. If only E_A is enabled, report B retains R, so the two equally likely report states earn 4alpha and 2, averaging 1+2alpha. If both specialists are enabled, each report can select its matching version and expected gross is 4alpha. Generalist E_0 provides 7/2 in each regime; adding it makes the best per-report payoff max(7/2,4alpha). All formulas are exact under the displayed assumptions.

The incremental gross value of paired source structure over one-sided source structure is **2alpha-1**, even though both sources yield the same ungrounded gross value of 2 at alpha=1/2. At alpha=3/4, one-sided source=5/2 and paired source=3. Thus a source that expands *which embodied policies can be qualified* can have no immediate contribution but positive value conditional on target grounding. For this policy menu, the extra paired source is worth acquiring only if its additional real costs and foregone opportunities are below its **incremental change in J**, not because a demonstration counts as 1/2 unit of data value.

The **new generalist body substitutes for grounding**: at alpha=3/4, independent E_0 yields 7/2, so adding either paired source policy and report generates no extra gross value in that window. Only if alpha > 7/8 does flexible paired specialization outperform the generalist at the stated payoffs. At perfect reporting, adding specialist options to retained R raises gross information value from zero to 2; adding generalist E_0 to already-available specialists *lowers* information value from 2 to 1/2. The corresponding cross differences are +2 and -3/2. Neither is a measured learning-transfer elasticity.

For a once-counted package cost C_XGE and independent generalist cost C_E0, conditional gross comparisons become 4alpha-C_XGE versus 7/2-C_E0. The derived package-preference criterion is alpha > (7/2+C_XGE-C_E0)/4 when the packages satisfy the same original customer service/rights/resource assumptions. Changes to the menu, physical capacity, production horizon, qualification uncertainty, capture or customer demand invalidate the numerical criterion; the general J remains controlling.

## An economically decisive negative result: report arrival versus irreversible hardware choice

The preceding 4alpha gain presumes both specializations can be deployed *after* the information arrives. If only **one** specialist body can be manufactured/locked in before report Y and an independently approved R fallback remains available after the report, the best conditional operation is

    max{W(R,E_A),W(R,E_B)} = 1+2alpha,

not 4alpha. At alpha=1 this is 3 rather than 4, despite identical technical competence conditional on the body. If the committed specialist instead removes R, and no action can change after Y, the report has **zero** operational decision value in this one-period model: the better ex-ante specialist earns 2, equal to R. This result depends on actual procurement/dispatch order; storing old weights does not make physical rescue feasible. A prior purchase choice and subsequent signal are distinct decisions.

This is the first discriminating mechanism to prioritize rather than another parameter sweep: **data can create policy options, but their economic option value depends on both report timing and the organizational/physical ability to exercise the newly learned option.** A more capable robust body can erase the premium on target data; a rigid body can erase an otherwise real information premium. It connects data transfer directly to manufacturing, operator scheduling, customer deadlines and generalist-versus-specialist choice without forcing a finance-only theory.

## Alternative assumptions and physical/empirical acceptance

- A changed body can alter not just policy feasibility but also the actual customer order kernel, product quality, price and operator resource constraints. Then keep policy-specific u(a,theta) and new menu terms; the fixed-law cross difference cannot be transported without evidence.
- Report quality can depend on source choice, and production-gathered target data are endogenously selected by prior deployment. The fixed-kernel theorem must not be used when X changes which states are visited; retain full-history potential-policy comparison with lawful positivity/transport or justified partial-ID sets.
- Irreversible hardware capital, lead time and operator substitution can make a source/grounding/embodiment package lose against R even if its flexible gross production is larger. Conversely free, optional source data only expands the menu if the old plan and rights are preserved. A forced retraining replacement may worsen production; this does not establish negative optimized value of free optional data.
- The illustrative payoff array requires **whole customer acceptance, safe qualified recipes, usable operator capacity and paid contribution in each cell**. It is *not* obtainable by multiplying benchmark success percentages by wages or revenues.
- A natural original buyer response differs from a binding warranty/commitment C. A demand signal must be measured at the intended original N version or with independently valid transport. An observed report cannot sign a post-failure recovery action.
- For multiorder or multilayer industrial production networks, replace each u with the full qualified V for an original buyer–robot–operator policy, including capacity sharing, rights and capture; continue the existing LP dual, qualification-bundle and dynamic policy arguments.
