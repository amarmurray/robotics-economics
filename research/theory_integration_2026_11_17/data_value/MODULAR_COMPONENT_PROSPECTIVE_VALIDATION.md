# Prospective matched component-identification contract — unpopulated

**20 November 2026. No participant recruited, no dataset copied, no robot trained, no physical trial conducted.**

**Estimand ladder.** First estimate only the value of a fully signed, randomized, update-closed *complete* X+G+E program versus the retained prelisted original policy. Second, if separately implementable hybrid policy components are signed and assigned, estimate all policy factorial cells and their predeclared policy-level contrasts. Third, if claiming source-modality mechanisms, use a genuinely matched offline intervention on a particular licensed source type, with identical initial weight hash, data budget, compute/curation schedule, embodiment, firmware, sampling/evaluation and held-out accepted-service recipe, and measure the full joint qualification/failure law. Fourth, connect only separately signed complete services to the original-customer paid production cohort. Do not substitute a technical benchmark for stage four.

**Unit and interference closure.** Construct one directed graph of controller weight updates, shared source ingestion, model checkpoint reuse, teleoperator attention, physical operator slots, dispatch coordination, customer order bundles and common manufacturing lead time. Assign entire connected components; declare and measure boundary leakage if any. No per-robot independence assumption when a global learner or order book is shared. Retain original buyer/offer version, price, demand-regime clock and pre-treatment intended service before observing qualification.

**Stop rules:** If source-specific rights are unclear, no extraction or training. If new body/weights hybrid not jointly approved, do not run it and do not label its counterfactual a physically feasible cell. If original customer paid receipt evidence is absent, do not report business-model data return. If complete-policy propensity is zero, do not use IPW for that cell; record sharp conditional bounds. A first valid safe offline trial should preferably distinguish genuinely different source modalities (deployment field, failures/recoveries, teleoperation, simulation, synthetic, public/pretrained), without privileging any one.
