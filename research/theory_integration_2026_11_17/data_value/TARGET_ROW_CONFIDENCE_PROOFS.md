# Proof ledger and negative checks — finite target-row data value

**November 19, 2026.** Conditional established mathematics, not robot field evidence or independent novelty.

**Simultaneous coverage.** For n_z>0 fixed independent conditional Bernoulli observations, P(|qhat_z−q_z|>epsilon_z)≤2 exp(−2 n_z epsilon_z²)=δ/m. Sum failures over m strata. n_z=0 gives [0,1]. Report-selected audit records fail this assumption; so does unadjusted clustered independence or optional stopping.

**Sharp confidence-set value.** For a fixed possibly stochastic π, q_z enters linearly in p_z[y_π(l,z)+q_z(y_π(h,z)−y_π(l,z))]. Minimizing a linear function on [ℓ_z,u_z] selects its appropriate endpoint. Independent row intervals permit joint attainment. The full policy-simplex maximum exists by compactness and continuity. A general adversarial maximin may need interior randomization: deterministic-only search is not sufficient for a universal theorem.

**Confidence sandwich.** On K*∈C, G(C)≤W(K*). For any π, differences across C are bounded by Σp_zR_z width(C_z) since |y_π(h,z)−y_π(l,z)|≤R_z. Apply to π* maximizing at K* to get W(K*)−G(C)≤Σp_zR_z width. No transfer from a frozen qualified physical menu to a changed controller is licensed.

**Allocation.** Minimize the unclipped bound cΣw_z n_z^{−1/2}, w_z=p_zR_z, Σd_zn_z≤B. Strict convexity and Lagrangian first-order conditions n_z∝(w_z/d_z)^{2/3} yield the unique positive interior optimum. This is not an optimal Bayesian experiment; data rights, shifts in demand and changed physical approval can alter the problem.

**Saddle check.** Under a known kernel, the value is linear in each report-specific action lottery, hence some deterministic rule attains its maximum. If G/S is optimal at the adverse corner (ℓ_H,u_L), the value of any randomized rule there is no greater; G/S's rectangle minimum occurs at that corner, so its robust value equals the ordinary corner optimum. Analogously any kernel where G alone is best yields a global 1 upper bound while constant G attains 1. Thus 16-rule enumeration *only at a fixed certifying kernel*, coupled with a matching worst-corner lower bound, is enough for these specific synthetic cases—not for arbitrary maximin games.

**Selected-label two-world impossibility.** Without the original opportunity denominator, and with inclusion only when report h, the conditional observed report is always h whether true low-row high probability is 2/5 or 3/5. Conditional on the same number of included orders, the selected records share the same distribution. Whole-population report contingent value changes (43/40 vs 1), establishing nonidentification. If the count of original opportunities, positive inclusion propensity or randomized audit sampling were known, the counterexample no longer supplies the same impossibility.

**Falsification.** Unknown customer capture y or demand p also invalidates numeric certificate; an unapproved service should be excluded from A, never assigned hypothetical payoff. Adaptive repeated sampling requires a confidence sequence; fixed-n bands are not anytime-valid. No numerical check is a proof of the general statements.
