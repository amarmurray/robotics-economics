# Instructor solutions — robust physical fallback and data economics

**Keep separate from the student packet.** Conditional finite-state mathematics, not a certified safety case.

1. W0=\{done\}; W1=\{done,retry\}; \`blocked\` stays outside because no remaining permitted physical action reaches the goal. Weights are not operator capacity or contracted time.

2. With two steps, the first outcome set \{\`done\`,\`retry\`\} is a subset of W1 and is admitted. The second set also contains \`blocked\`, which is outside W1; an adverse first-step realization defeats R-only recovery. A high expected X success rate says nothing about that possible transition under a universal guarantee.

3. The physically admissible recipe can still be economically inferior when priced/accepted service and displaced resource costs are included. Retained R is preferable for current net production under the given comparison. Future data enters only through the discounted J continuation, net of legitimate collection/curation/rights expenses, and cannot be added a second time.

4. A newly documented permissible old recovery action can expand the old winning set (if all its physically possible successors are winnable); training that changes only visit probabilities or marginal accuracy need not. Compare versioned transition support, observed postfailure state and clock, shared operator schedule, and licensed recovery permissions, together with original buyer accepted service.
