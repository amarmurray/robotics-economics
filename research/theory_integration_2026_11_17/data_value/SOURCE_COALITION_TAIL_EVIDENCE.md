# Prospective source-mixture target-market validation (not observed field evidence)

**Purpose.** Determine whether paired source-coalition SG/E economics can transport to F+T+M pooled training, and whether buyer-class/source-neighborhood locality holds. This is a pre-registration template, not an approved trial or customer dataset.

1. **Common target market:** define eligible original buyer/order population N before program or source allocation; record declined/non-offered/failed and zero-paid orders, end-market, value chain, contract, SLA, refund and displaced outside work. Track production-induced demand and substitutions, keeping consistent initial population.
2. **Interventions and permissions:** enumerate complete SG, E, R and other actually signed controller/embodiment/target-grounding packages, old fallback, robot/operator safety, input source rights and cross-customer data retention. F field successes/failures/recoveries, T teleoperation, M simulation/synthetic, public/pretrained and production-generated datasets remain independently versioned; no training or customer outreach is authorized by this document.
3. **Matched technical and economic outcomes:** for each lawfully assigned *whole* learner/operator/buyer network capture source-coalition availability, training/curation cost, actual source use, checkpoint lineage, joint accepted-service qualifications, physical attempts, operator time, buyer offer/acceptance and settled contribution. A benchmark alone does not identify J.
4. **Factorial support:** distinguish observable lower-coalition means at **N fixed** from isolated m-site training. Report exact legal support for each a×A×pool/cut and composition; mark physically excluded E or triple arm as missing, not as zero.
5. **Locality falsification:** audit pre-declared source ancestry H_i and full-horizon influence graph, shared model, cross-customer operators, price/buyer procurement, material/manufacturing bottlenecks, external order displacement. One global checkpoint or bottleneck defeats unqualified k-locality. Check per-buyer exposures across source mixes; if higher-order effects can be observed, test theta(FTM)=0 rather than assuming it.
6. **Extrapolation:** if full triple arm missing, compute only the identified order-2 prediction plus explicit unknown remainder; seek a defensible complete-paid upper capacity bound and monotone optionality only if true. Predeclare valid joint confidence coverage, original buyer-class reweighting, unsupported-class mass and legally supported network replicates. No high-order bound can be inferred just from local data efficiency.
7. **Backbone:** preserve BEA/BLS industry classification, year, vintages, flow units and numerical table route if independently verifiable; no wage=robotic revenue shortcut or substitute vendor claim.

**Current evidence status:** All examples synthetic. No approved full-fleet SG/E comparison, lawful source-mixture experiment, actual original-customer receipt, observed source graph/tail, measured sector input-output coefficient or independent review. Nov22 scientific acceptance remains open.
