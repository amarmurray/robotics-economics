# Instructor solutions — original-buyer SG/E exposure under shared learning

**Keep separate from student materials. All numbers are synthetic.**

1. If `I_i^1=1` denotes that every predeclared assignment ancestor in `H_i` uses SG, then on this event exposure sufficiency implies `Y_i(Z)=Y_i(1_N)`. With `P(I_i^1)=p^{|H_i|}`, `E[I_i^1 Y_i(Z)/p^{|H_i|}]=Y_i(1_N)`; averaging over all original buyers identifies the fixed-market all-SG mean. A direct effect conditioned on mixed neighbors is not the all-program regime. Shared global learning, operators, buyers, displaced orders and continuation-data updates all enter `H_i`.
2. For same-arm exposures `P(I_i^a I_j^a)=p_a^{|H_i\cup H_j|}`. Therefore the covariance of two weighted fixed contributions is `y_i^a y_j^a(p_a^{-|H_i\cap H_j|}-1)`. For opposite-arm exposures with overlapping sets, joint occurrence is impossible and covariance equals `-y_i^1 y_j^0`; it is zero when disjoint. Sum all ordered pairs and divide by N². `Var(SG-E)=Var(SG)+Var(E)-2Cov(SG,E)`; cross-arm covariance is generally negative.
3. Target all-SG mean is `54/80=27/40`, all-E mean is `44/80=11/20`; gap `1/8`. Enumerating all 16 equally likely vectors produces `Var(SG)=2127/1600`, `Var(E)=129/160`, covariance `-33/100`, contrast variance `4473/1600`. With `B=1,d=3,M=4,N=4`, the simple variance upper bound is 16 and is uninformative about a gap of only 1/8. See exact JS and independent Fraction checker. This is not evidence SG is better in the field.
4. All original buyer outcomes can depend on all assignments through the shared updated checkpoint, so each `H_i` becomes all N units. Either entire vector is homogeneous with probability `2(1/2)^N=2^{1-N}`; at N=20 this is `1/524288`. Extra trajectories from one shared learner do not make the independent assignment vector repeat.
5. If the old feasible policy set is `P` and optional free new data enables `P'\supseteq P` without new costs/rights/resource changes, `max_{p\in P'} V(p)\ge max_{p\in P} V(p)`. Forcing retraining has different feasible and cost sets. Its shared deployed checkpoint can make assignment ancestors global, driving any Bernoulli exposure probability to `p^N` or `(1-p)^N`; optimized economic value and statistical comparison precision need not move together. Report accepted buyer production and later licensed data effects only once in the continuation value.
