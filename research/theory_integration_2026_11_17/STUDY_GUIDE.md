# Theory study guide—attempt before opening SOLUTIONS.md

## 1. A capability with zero standalone value

Two machines each provide one capacity unit. Customer demands are one unit each, with contributions 2 and 1. Initially only machine 1 can serve task 0. New qualifications are e0: machine 0 to task 0, and e1: machine 1 to task 1.

Derive the operating value with neither, each separately, and both qualifications. Explain why testing only the marginal value of each isolated qualification would miss a profitable joint investment. State a competent alternative that could eliminate this result in a real site.

## 2. Customer demand changes the learning economics

Build the three-machine chain in the manuscript, task contributions 3,2,1. Independently qualify each new edge with probability p. Derive incremental expected value. Then permit two units of task-0 demand while retaining all other physical and technical assumptions. Recompute. Does this require the robot to learn faster?

## 3. A learning-budget allocation

For two complementary requirements with technical responses 1-exp(-a_i u_i), total effort 2, and a1=1,a2=2, write the first-order condition. Is equal effort optimal? Explain why allocating everything to the more effective learning channel fails. Use the provided code only after writing the conditions.

## 4. Distinguish a cash limit from expenditure

For three missing requirements, payoff10, rate1, compare a maximum budget1 under batch commitment and adaptive observed/retained acquisition. Explain why subtracting the full budget1 from adaptive expected payoff would be wrong. Identify the information and retention assumptions that permit the difference.

## 5. Shared learning is not uniformly superior

Two qualification probabilities are each .2. Compare independent outcomes with perfectly shared qualification for (a) values 0,0,0,1 and (b) values 0,1,1,1. Compute the economic interaction and expected values. Explain why common-mode failure during field operation is a different object.

## 6. What would falsify the mechanism?

Design an observation or experiment that distinguishes a two-qualification complementarity from an apparently similar result caused by low customer demand, scarce human supervision, or a missing human/fixture alternative. Specify accepted output, the joint technical outcome, customer value, and the same-resource comparison. Do not call an observational difference-in-differences contrast causal without identifying its assumptions.
