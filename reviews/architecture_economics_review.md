# Conditional architecture economics: implementation audit

25 October 2026. **Sole-lead verification under the one-agent limit.** Model 0.3.0 accepts the bounded K mechanism scenario. No independent reviewer, real vendor-price estimate, rights clearance, physical qualification or company-financing proof is claimed.

## Accounting and boundaries

The new comparison calls the existing matched-service equations and adds disjoint resource charges and explicit transfers across customer, operator, OEM, model supplier and integrator roles. Combining roles eliminates internal payments, not work or costs. The scalar robot digital-service bundle is replaced by itemized model expenses rather than charged twice. Original scalar numerical results remain unchanged.

One-time costs, annual expenses and payments are separate. Integer cents conserve the complete allocated case schedule; annual equivalents divide lifetime amounts. Capital consumption is not subtracted again from cash. Unavoidable released-payroll cash reduces the cash proxy while the resource comparison retains its opportunity-cost boundary; observed payroll removal remains null. The upstream development charge is an explicit allocation, not an observed lab cash calendar.

Fee bounds hold other payments fixed, include upfront charges and round to admissible integer-cent prices. Bilateral feasibility is distinguished from losses at other counterparties. Combined entities have no external fee to solve for. The case fixes operator purchase and current-year conditions through service life. It simulates no opening balance, credit, default, cancellation, discounting or within-year working capital. Positive annual equivalents do not establish financing.

All 69,315 legacy scalar numerical fields still match across sixteen preset/configuration cases. New source identities include the architecture helper/catalog and full effective parameters. **36 JavaScript assertions** and syntax checks pass. The actual source alternatives retain unknown prices and qualification; none of the source scores is imported as a numerical coefficient.

Browser testing exposed unreliable blur-triggered numeric application and the possibility of overwriting another edit during immediate recalculation. The corrected UI uses **Apply architecture assumptions**, labels pending edits and retains the last valid result on rejection. Applied fee and adaptation changes affected the intended outputs, a false compatibility premise removed the case from ranking, and blank numeric input was rejected. Export/reload restored parameters and selected scope. Final publication receipts distinguish these checks from intermediate snapshots.

## Interpretation and remaining work

Eight separate witnesses show that fees redistribute an existing gain; more adaptation changes cost without directly improving output; intervention affects support and robot contribution while human fallback preserves total service; leaner open adaptation can reverse a cost ranking; and a stronger digital-human alternative can reduce robot value while combined cost falls. Newco labels alone change no technology; explicit extra setup costs do.

The bounded W1-K-ARCHITECTURES scenario target is met. These constructed alternatives are not named-product rankings or simultaneously feasible fleets. The shared monthly commercial/title/physical model, separate operator/financier obligations, funding timing, retention, portfolio capacity and calibrated field economics remain unfinished. They are the next task, not implied achievements of this static reference.
